# Glamz Studio Unisex Salon Website

## Files
- `index.html` — website structure and content
- `style.css` — responsive black, champagne-gold and ivory design
- `script.js` — mobile menu, gallery lightbox, back-to-top and WhatsApp enquiry form

## Run locally
1. Extract the ZIP file.
2. Open the `glamz-studio-website` folder in your code editor.
3. Open `index.html` in a browser. You can also use a simple local server if you have one.

## Before publishing
- Verify the salon's full address and exact Google Maps pin.
- Verify any public rating and review count before displaying it.
- Replace sample Unsplash photos with the salon's own photos where possible.
- The appointment form opens WhatsApp with the enquiry details. It does not store appointments or confirm a booking.
- Phone and WhatsApp links use the number provided in the brief.
- Social profile links were not supplied, so none have been invented.
- Opening hours are set to 10:00 AM–8:30 PM daily as supplied; verify holiday hours.
- Google Fonts and Unsplash images require an internet connection.
